# BranchMap

本机的 Git 可视化工具。一个仓库一页，看提交图、dev 与 main 的差距、每条分支的合并进度、文件历史和成员动态。

只读：除了顶栏手动点的「同步远程」（`git fetch --all --prune`，只更新远程分支），只跑 `log` / `show` / `diff` / `blame` / `status` 这类查询命令，不切分支、不改工作区。服务只监听 `127.0.0.1`。

## 用法

需要 Node 20+ 和 Git。想看 PR 和 GitHub 头像，再装一个登录过的 [GitHub CLI](https://cli.github.com/)（`gh auth login`）。

```bash
npm install
cp config.example.json config.json   # 把 root 改成放仓库的那个目录
npm start                             # 启动并打开 http://localhost:4317/
```

`npm run serve` 只启动不开浏览器，也可以在 VS Code 的内置浏览器里打开这个地址。数据是实时的：切回页面时会自动检查仓库有没有变化，顶栏的刷新按钮会重新读一次。

## 每一页

- **概览**：第一块是主线，`dev` → `main` 的示意图，外加四个数：待上线（dev 有、main 没有）、未回合（main 有、dev 没有）、上次 dev → main、分叉点。下面是两边独有的内容，按合并（PR）分组列出。本地 main / dev 和远程不一致时会提示。其余几块是分支状况、近 14 天成员动态、打开的 PR、版本标签和本机工作区（含未提交的文件）。
- **提交图**：带泳道的全部历史。main 的第一父链固定在最左道（蓝），dev 固定在第二道（橙）。「主线」预设只看这两条线，能看清它们怎么分叉、谁合进了谁。可以按分支、按人筛选，按说明、哈希或作者搜索。未提交的改动显示在对应提交的上方。右边是提交详情：什么时候进的 dev / main、第一次发布在哪个标签、在哪些分支里，以及改了哪些文件。点文件看差异，支持统一 / 并排、忽略空白、全文，带语法高亮和行内改动标记。
- **分支**：每条分支相对 dev 和 main 的领先 / 落后、合并进度（什么时候进的 dev / main）、本地和远程是否一致、PR、在哪个工作树检出。按进行中、待上线、停滞、已上线分组。另有「标签」页，以及「对比」页：任选两个引用，看分叉点、各自独有的提交和文件差异。
- **文件**：任意分支或标签下的文件树。可以看文件内容、这个文件的历史（每次改了什么），以及逐行追溯（blame）。
- **统计**：提交热力图、按人的每周提交、增删行、累计行数、提交时间分布、贡献者、改得最多的文件。可以按范围（全部分支 / main / dev）和时间筛选。
- **成员**：每个人手上在做的分支（相对 dev / main 差多少）、最近合进去的工作、每周提交、最近的提交、常改的文件。

## 几个约定

- 主线自动识别：`origin/HEAD` 指向的分支，或者 `main` / `master` 当 main；`dev` / `develop` 当 dev。识别不对的，在 `config.json` 里按仓库名指定：`"trunk": { "仓库名": { "prod": "main", "dev": "dev" } }`。
- 本地分支和同名的 `origin` 分支合成一条。两边不一致时，按较新的一方算（一方是另一方的祖先就取新的，分叉了取提交时间新的）。
- 分支状态以 dev 为准（没有 dev 的仓库以 main 为准）：有自己的提交、14 天内动过的算进行中，超过 14 天没动的算停滞；进了 dev 没进 main 的是待上线，进了 main 的是已上线。
- 分支的负责人，取它自己的提交里出现最多的作者。
- 同一个人的多个 Git 名字，按邮箱和 GitHub 账号自动合并。还有漏的，在 `aliases.json` 里写 `{ "显示名": ["名字1", "名字2"] }`。
- 头像来自提交关联的 GitHub 账号，查过的结果缓存在 `.cache/`。
- 临时目录（系统 Temp、`C:\Temp`）里的工作树默认折叠。

## 配置

`config.json`（不进仓库）：

| 字段 | 说明 |
|---|---|
| `root` | 放仓库的目录，下面每个含 `.git` 的子目录算一个仓库；也可以是目录数组 |
| `repos` | 额外单独加的仓库路径（数组，可选） |
| `port` | 端口，默认 4317 |
| `trunk` | 按仓库名指定主线分支（可选，见上） |

命令行 `--root=` 和 `--port=` 会覆盖 `config.json` 里的同名设置。
