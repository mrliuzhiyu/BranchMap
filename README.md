# BranchMap 分支地图

一个目录下放着好几个 Git 仓时，用一页看清所有项目现在的状态：谁在做哪条分支、哪些已经进了 dev 等着上线、哪些已经上线、本地有哪些文件还没提交。

只读。除了 `git fetch` 更新远程分支，不切分支、不改任何工作树。

## 用法

需要 Node 20+、Git，以及登录过的 [GitHub CLI](https://cli.github.com/)（`gh auth login`，用来读 PR 和头像）。

```bash
cp config.example.json config.json   # 把 root 改成放仓库的那个目录
npm run collect                       # 采集，生成 data.js（约半分钟）
```

然后用浏览器打开 `index.html`。数据要更新就再跑一次 `npm run collect`，刷新页面。

## 页面上有什么

- **每个项目三列**：进行中 → 待上线（已进 dev、没进 main）→ 已上线（近 14 天进了 main）。一条分支一张卡：头像、谁的、多久以前、比 dev 多几个提交、PR。
- **项目标题行**：本地检出的分支、未提交文件数、未推送的提交。点「未提交」按工作树列出每个文件和增删行数；Temp 目录里的临时工作树折叠在最后。
- **查看分支**：下拉选任意分支看它的提交，只是展示，不会真的切过去。
- **成员**：左侧点头像，只看这个人在所有项目里的分支。

## 几个约定

- 一条分支「自己的工作」以 `dev` 为准算；没有 `dev` 的仓退回 `main`/`master`。
- 超过 14 天没有新提交的「进行中」分支算停滞，折叠在列底部。
- 同一个人的多个 Git 名字按邮箱和 GitHub 账号自动合并；还有漏的，在 `aliases.json` 里写 `{ "显示名": ["名字1", "名字2"] }`。
- 头像来自提交所关联的 GitHub 账号，没关联的显示首字。
- 未提交文件只看得到这台电脑上的工作树。

`data.js`、`config.json`、`aliases.json` 都只留在本机，不进仓库。
